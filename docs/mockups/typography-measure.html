字距不是全局一个值。 34px 的标题用 0 字距会显得松散，10px 的全大写标签用 0 字距会粘成一团。 所以每一档都带自己的 tracking：display −0.7 / title −0.5 / heading −0.2 / body 0 / small +0.1 / caption +0.2 / label +1.8。
行距按倍数给，不是写死行高。 衬线正文 1.62~1.80，标签类只要 1.40 —— 差别很大，用一个固定行高会两头都不对。阅读正文的行高倍数仍由主题给（默认主题 1.7 / 叙拉古 1.8）。
数字用等宽数位。 统计数字会变（37 → 128），比例数位会让它左右跳动； font-variant-numeric: tabular-nums 才不会。上排三个数字宽度一致。
字体族现在全是系统回退。 内嵌自有显示字体需要装包，本环境网络与 npm 都被拦。 代码里已经留好插槽（constants/typography.ts 的 FONT_SLOTS）， 装好之后改四个字符串即可，其余不用动。
