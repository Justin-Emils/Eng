浅色是衍生、不是还原。 7 张参考图暗部占比 48%–78%，没有任何浅色界面。 所以浅色只保留同一套色族（靛紫强调 + 绯红标注 + 金线）反转过来， 在文档里也标注为"衍生"，不当成对活动的还原。

还没做的：形态。 这次只换了配色（可从像素可靠量出）。 描边粗细、角标形状、字距节奏、字体族这些量不出语义， 需要视觉模型恢复或你的文字描述——目前的衬线 + 方直角 + 金刻线仍是我按"印刷品"编的。
